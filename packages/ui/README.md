# @custom/ui

Shared React components, Tailwind styles and translatable strings for all
frontends, developed in Storybook. Route components are the entry points that
apps render; they fetch their own data through GraphQL operations from
`@custom/schema`.

## Structure

- `src/components/Routes` - page-level components, exported as
  `@custom/ui/routes/<Name>` (e.g. `Page`, `Frame`, `Preview`).
- `src/components/{Atoms,Molecules,Organisms}` - building blocks.
  `src/components/Client` holds `'use client'` components.
- `src/utils` - `withOperation`, `useOperation` and `useMutation` (SWR-based)
  wrappers around the `<Operation>` component and executors from
  `@custom/schema`, plus other helpers.
- `src/helpers` - `image` helper for stories, Storybook `ExecutorsDecorator`.
- `src/tailwind.css` - main stylesheet; `src/iframe.css` - styles for Drupal
  markup rendered in iframes (e.g. webforms), mapping Drupal classes to Tailwind
  with `@apply`.
- `static/public` - layout assets and fonts (`fonts/preload` files are
  preloaded), served at `/` by Storybook and the apps.
- `static/stories` - content images for stories, imported via `@stories/`.
  `static/stories/webforms` is generated by `@custom/webform-export`.

UI text uses `useIntl` / `intl.formatMessage` from `@amazeelabs/react-intl`.

## Development

```shell
pnpm dev               # Storybook on http://localhost:6006
pnpm test:unit         # vitest
pnpm build             # static Storybook in storybook-static/
pnpm test:integration  # test runner (play functions, axe) on built Storybook
```

Build artifacts (`build/`) are produced by the Turborepo `prep` task
(`pnpm turbo:prep` from the root): `build/components/**` (JS + types),
`styles.css`, `iframe.css`, `gutenberg.css` (prefixed for the Gutenberg editor),
`preloaded-fonts.json` and `translatables.json` (extracted messages).

In Storybook, every story is wrapped with `IntlProvider`, `LocationProvider` and
an `ExecutorsDecorator` that mocks operations through the `executors` story
parameter. `@amazeelabs/bridge` is aliased to `@amazeelabs/bridge-storybook`.

See the root README for [Storybook](../../README.md#storybook) deployment and
[layout](../../README.md#layout-images),
[content](../../README.md#content-images) and
[responsive](../../README.md#responsive-images) images.

## Dependencies

- Depends on: `@custom/schema`, `@amazeelabs/react-intl`,
  `@amazeelabs/silverback-iframe`; `@amazeelabs/bridge-storybook` (dev).
- Used by `@custom/website`: routes, `styles.css`, `iframe.css`,
  `static/public`, `preloaded-fonts.json`.
- Used by `@custom/preview`: `Frame` and `Preview` routes, `styles.css`,
  `static/public`.
- Used by `@custom/decap`: `Page` and `Frame` routes, `styles.css`,
  `translatables.json`.
- Used by `@custom/cms`: `iframe.css` and `gutenberg.css` (symlinked in `web/`),
  `translatables.json` (`pnpm import-translations`).
- Used by `@custom/gutenberg_blocks`: loads `/gutenberg.css` in the editor.
